# Glyph Exposure

This repository is intended to implement the mere-exposure experiment described [here](https://dgmulf.github.io/lab-wiki/computational-aesthetics.html#mere-exposure-glyphs-on-cards). The experiment tests whether behavioral network optimization can reproduce the human ideograph liking curve reported in Table 3 of Montoya et al., 2017, and learn a perceptual prior in fewer card draws than a control optimizing cross-entropy against a simple empirical distribution.
